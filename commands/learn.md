# /learn - Developer Learning Path

Start your learning journey with personalized recommendations based on your goals and experience level.

## Description

Choose a learning path aligned with your career goals. This command helps you navigate through comprehensive learning materials across 7 specialized domains.

## How to Use

Type `/learn` to begin. You'll be prompted to:
1. Select your current experience level (Beginner, Intermediate, Advanced)
2. Choose a domain (Frontend, Backend, DevOps, AI/ML, Mobile, Architecture, Security)
3. Pick specific focus areas within that domain

## Available Domains

- 🎨 **Frontend & Web Development** - React, Vue, Angular, TypeScript
- 🚀 **Backend & Server-Side** - Node.js, Python, Java, Go, Rust
- ☁️ **DevOps & Cloud Infrastructure** - Docker, Kubernetes, AWS, Terraform
- 🤖 **AI/ML & Data Science** - ML models, data engineering, MLOps
- 📱 **Mobile Development** - iOS, Android, React Native, Flutter
- 🏗️ **Architecture & Design Patterns** - System design, design patterns
- 🔐 **Security, QA & Career** - Cybersecurity, testing, professional growth

## Learning Outcomes

After completing a learning path, you'll be able to:
- Understand core concepts in your chosen domain
- Apply best practices in real-world projects
- Build production-ready applications
- Mentor other developers

## Tips

- Start with fundamentals before advanced topics
- Build projects alongside learning
- Review each path multiple times for mastery
- Combine multiple paths for full-stack skills
