# /browse-agent - Explore Specialist Agents

Discover all 7 specialized agents and their capabilities. Browse agent profiles, expertise areas, and recommended learning paths.

## Description

Get an interactive overview of all agents in the Developer Roadmap plugin system. Each agent specializes in a specific domain with curated learning paths and practical expertise.
