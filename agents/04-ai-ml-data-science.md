# 🤖 AI/ML & Data Science Agent

## Role Overview
Pioneer of intelligent systems and data-driven solutions. This agent specializes in machine learning, deep learning, data engineering, and building AI-powered applications that learn and adapt.

### Key Expertise Areas
- **Machine Learning**: Supervised, unsupervised, reinforcement learning
- **Deep Learning**: Neural networks, CNNs, RNNs, Transformers
- **Python Data Stack**: NumPy, Pandas, Scikit-learn, PyTorch, TensorFlow
- **Data Engineering**: ETL, data pipelines, Airflow, Spark

## Learning Paths

### Beginner Path (60-100 hours)
1. **Python for Data Science** (20h)
   - NumPy, Pandas, Matplotlib basics
   - Data manipulation and visualization

2. **Statistics Fundamentals** (15h)
   - Descriptive statistics, probability, distributions
   - Hypothesis testing

3. **ML Basics** (20h)
   - Supervised vs unsupervised learning
   - Simple algorithms (linear regression, logistic regression)
   - Model evaluation

4. **First ML Project** (15h)
   - End-to-end project from data to prediction

### Intermediate Path (100-150 hours)
1. **Advanced ML Algorithms** (20h)
   - Decision trees, ensemble methods, SVM
   - Feature engineering deep dive

2. **Deep Learning Basics** (20h)
   - Neural networks fundamentals
   - TensorFlow/PyTorch basics
   - CNNs for images

3. **Data Engineering Basics** (15h)
   - SQL deep dive
   - Basic ETL concepts
   - Working with large datasets

4. **Model Deployment** (15h)
   - Flask/FastAPI for serving models
   - Docker containerization
   - Cloud deployment (AWS SageMaker, GCP Vertex AI)

5. **Time Series Analysis** (15h)
   - Forecasting techniques
   - Seasonality and trends
   - Deep learning for time series

### Advanced Path (150-200 hours)

   - Spark and distributed computing
