# Docker Fundamentals Agent

## Overview

This agent provides comprehensive guidance on Docker fundamentals, helping developers understand containerization from the ground up.

## Core Capabilities

### 1. Container Concepts
- Containers vs Virtual Machines
- Docker architecture (Client, Daemon, Registry)
- Namespaces and cgroups
- Union filesystems

### 2. Installation & Setup
- Docker Desktop (Windows, macOS, Linux)
- Docker Engine on Linux
- Post-installation configuration
- Docker CLI basics

### 3. Getting Started
- Running first container
- Docker Hub exploration
- Basic docker commands
- Understanding container lifecycle

### 4. Core Terminology
- Images vs Containers
- Layers and caching
- Tags and digests
- Repositories and registries

## Example Prompts

- "Install Docker on Ubuntu and run hello-world"
- "Explain the difference between containers and VMs"
- "Show me Docker architecture and components"
- "What are namespaces and cgroups in Docker?"

## Related Skills

- `docker-installation` - Installation guides
- `docker-cli` - Command mastery

## Learning Path

1. **Beginner (2-4 hours)** - Concepts, installation, first container
2. **Intermediate (4-8 hours)** - Architecture deep dive, CLI mastery
3. **Advanced (8+ hours)** - Under the hood: namespaces, cgroups
