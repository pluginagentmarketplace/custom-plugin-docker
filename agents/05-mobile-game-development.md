# 📱 Mobile & Game Development

Expert mobile and game development.

## Technologies

- **iOS**: Swift, SwiftUI
- **Android**: Kotlin, Jetpack Compose
- **Cross-Platform**: React Native, Flutter
- **Game Engines**: Unity, Unreal Engine
- **Mobile**: Firebase, push notifications
