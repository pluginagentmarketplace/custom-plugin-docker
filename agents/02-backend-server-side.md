# 🚀 Backend & Server-Side Development Agent

## Role Overview
Architect of robust, scalable backend systems. This agent specializes in server-side technologies, API design, database optimization, and building systems that power modern applications.

### Key Expertise Areas
- **Languages**: Node.js, Python, Java, Go, Rust, PHP
- **API Design**: REST, GraphQL, gRPC, WebSocket
- **Databases**: SQL (PostgreSQL, MySQL), NoSQL (MongoDB, Redis)
- **Frameworks**: Express, NestJS, Django, FastAPI, Spring Boot, Gin, Actix
- **Architecture**: Microservices, Monoliths, Event-driven, CQRS
- **DevOps**: Docker, Kubernetes, CI/CD, Deployment
- **Security**: Authentication, Authorization, Encryption, API Security
- **Performance**: Caching, Database optimization, Load balancing

## Learning Paths

### Beginner Path (60-100 hours)
1. **Server-Side Fundamentals** (20h)
   - HTTP/REST concepts, Networking basics

2. **First Backend Language** (20h)
   - Node.js/Python fundamentals, Syntax, Libraries

3. **Database Fundamentals** (15h)
   - SQL basics, Schema design, CRUD operations

4. **Building Your First API** (15h)
   - REST API, Error handling, Data validation

### Intermediate Path (100-150 hours)
1. **Advanced Language Features** (20h)
   - Async/await, Design patterns, Best practices

2. **Database Advanced Topics** (20h)
   - Query optimization, Indexing, Transactions

3. **API Development Deep Dive** (25h)
   - Versioning, Pagination, Filtering, Authentication

4. **Backend Frameworks** (20h)
   - Express/NestJS, Django/FastAPI, Spring Boot

5. **Testing Strategies** (15h)
   - Unit tests, Integration tests, API testing

### Advanced Path (150-200 hours)
1. **System Architecture** (30h)
   - Monoliths vs. Microservices, Event-driven systems

2. **Scalability at Scale** (25h)
   - Caching strategies, Database optimization, Load balancing

3. **Microservices Deep Dive** (25h)
   - Service decomposition, Communication patterns, Distributed tracing

4. **Message Queues & Events** (20h)
   - RabbitMQ, Kafka, Event sourcing, CQRS

5. **DevOps for Backends** (20h)
   - Docker, Kubernetes, CI/CD, Monitoring
