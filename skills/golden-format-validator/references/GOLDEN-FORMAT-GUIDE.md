# Golden Format Guide

Comprehensive guide to understanding and implementing the Golden Format for Claude Code plugin skills.

## What is Golden Format?

The Golden Format is a standardized directory structure and content requirement for skills in Claude Code plugins. It ensures consistency, discoverability, and quality across all skills.

## Required Structure

```
skill-name/
├── SKILL.md              # Required, > 200 bytes
├── assets/               # Required, with real content
│   ├── config.yaml       # Configuration
│   └── schema.json       # Input/output schema
├── scripts/              # Required, with real content
│   └── validate.py       # Validation script
└── references/           # Required, with real content
    ├── GUIDE.md          # Usage guide
    └── PATTERNS.md       # Best practices
```

## SKILL.md Requirements

### Minimum Size

SKILL.md must be at least **200 bytes**. Files smaller than this are flagged as E701 violations.

### Required YAML Frontmatter

```yaml
---
name: skill-name
description: Brief description of what the skill does
sasmp_version: "1.3.0"
bonded_agent: parent-agent-name
bond_type: PRIMARY_BOND  # or SECONDARY_BOND
---
```

### Required Fields

| Field | Type | Description |
|-------|------|-------------|
| name | string | Unique skill identifier (lowercase, hyphens) |
| description | string | Clear description of skill purpose |
| sasmp_version | string | SASMP protocol version ("1.3.0") |
| bonded_agent | string | Name of parent agent |
| bond_type | enum | PRIMARY_BOND or SECONDARY_BOND |

### Recommended Sections

- Purpose
- Parameters (table format)
- Usage examples
- Error handling
- Related skills

## assets/ Directory

### What It Contains

Configuration files, schemas, templates, and other static assets.

### Required Content

At least one real file (not just .gitkeep or small README).

### Recommended Files

| File | Purpose |
|------|---------|
| config.yaml | Skill configuration |
| schema.json | JSON Schema for input validation |
| templates/ | Template files (if applicable) |

### E702 Violation

Triggered when assets/ contains only:
- `.gitkeep`
- `README.md` with < 100 bytes

## scripts/ Directory

### What It Contains

Executable scripts for validation, automation, or tooling.

### Required Content

At least one real script file.

### Recommended Files

| File | Purpose |
|------|---------|
| validate.py | Input/config validation |
| setup.sh | Setup automation |
| test_*.py | Test files |

### E703 Violation

Triggered when scripts/ is empty or placeholder-only.

## references/ Directory

### What It Contains

Documentation, guides, and reference materials.

### Required Content

At least one real documentation file.

### Recommended Files

| File | Purpose |
|------|---------|
| GUIDE.md | Comprehensive usage guide |
| PATTERNS.md | Best practices and patterns |
| API.md | API reference (if applicable) |

### E704 Violation

Triggered when references/ is empty or placeholder-only.

## Validation

### Manual Check

```bash
# Check SKILL.md size
wc -c skills/my-skill/SKILL.md

# Check subdirectory contents
ls -la skills/my-skill/assets/
ls -la skills/my-skill/scripts/
ls -la skills/my-skill/references/
```

### Automated Validation


## Fixing Violations

### Using golden-format-fixer

```bash
# Fix all violations
python golden-format-fixer/scripts/fix.py /path/to/plugin

# Dry run first
python golden-format-fixer/scripts/fix.py /path/to/plugin --dry-run
```

### Manual Fix

1. **E701**: Add or expand SKILL.md with proper frontmatter and documentation
2. **E702**: Add config.yaml and schema.json to assets/
3. **E703**: Add validate.py to scripts/
4. **E704**: Add GUIDE.md and PATTERNS.md to references/

## Best Practices

1. **Start with SKILL.md** - Write comprehensive documentation first
2. **Use templates** - Leverage golden-format-fixer templates
3. **Validate early** - Run validation before committing
4. **Category-aware content** - Match content to skill category
