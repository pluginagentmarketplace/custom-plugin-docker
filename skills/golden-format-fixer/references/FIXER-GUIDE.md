# Golden Format Fixer Guide

Complete guide for using the Golden Format Fixer to automatically repair E701-E704 violations.

## Overview

The Golden Format Fixer is a specialized tool that automatically repairs Golden Format compliance violations in Claude Code plugin skills. It has been field tested on 378 skills with a 100% success rate.

## What It Fixes

| Error Code | Violation | Fix Action |
|------------|-----------|------------|
| E701 | Missing/small SKILL.md | Generate comprehensive SKILL.md (50+ lines) |
| E702 | Empty assets/ directory | Add config.yaml + schema.json |
| E703 | Empty scripts/ directory | Add validate.py (100+ lines) |
| E704 | Empty references/ directory | Add GUIDE.md + PATTERNS.md |

## Usage

### Command Line

```bash
# Fix all skills in plugin
python scripts/fix.py /path/to/plugin

# Dry run (preview only)
python scripts/fix.py /path/to/plugin --dry-run

# Fix specific skill
python scripts/fix.py /path/to/plugin --skill api-client
```

### Programmatic

```python
from fix import fix_skill

# Fix single skill
result = fix_skill(Path("/path/to/skill"))

# Check results
print(f"Fixed {len(result['fixes'])} violations")
```

## Category Detection

The fixer automatically detects skill category from the name:

| Category | Detection Patterns | Generated Content |
|----------|-------------------|-------------------|
| api | api, rest, graphql, http | API-focused configs |
| testing | test, spec, qa | Test configurations |
| devops | deploy, ci, cd, pipeline | Pipeline templates |
| security | auth, security, encrypt | Security policies |
| health | health, monitor, diagnostic | Health check tools |
| general | (default) | Generic templates |

## Safety Features

### Automatic Backups

Before any fix, a backup is created:

```
/tmp/golden-format-backup/
├── skill-name_20251230_143000/
│   ├── SKILL.md
│   ├── assets/
│   ├── scripts/
│   └── references/
```

### Dry Run Mode

Preview changes without applying:

```bash
python scripts/fix.py /path/to/plugin --dry-run
```

Output:
```
DRY RUN MODE
Would fix 4 skills:
  - api-client: E702, E703, E704

```

## Best Practices

1. **Always run dry-run first** to preview changes
2. **Review generated content** after fixing
3. **Customize templates** for your specific needs
4. **Keep backups** for at least 7 days

## Troubleshooting

### Fix Not Applied

1. Check write permissions
2. Verify skill directory exists
3. Run with verbose mode

### Wrong Category Detected

Override with explicit category:

```bash
python scripts/fix.py /path/to/plugin --category api
```

### Content Not Matching

Customize the template files in `assets/templates/` for your needs.
